# 경어 MOC

겸양어·존경어 등 경어 관련 단어 모음.

- [[伺う]] — うかがう / 여쭙다·찾아뵙다·듣다 (聞く·尋ねる·訪ねる의 겸양어)
- [[参る]] — まいる / 가다·오다의 겸양어
- [[申し上げる]] — もうしあげる / 말씀드리다 (言う의 겸양어)
- [[拝見]] — はいけん / 삼가 봄 (見る의 겸양어)
- [[いただく]] — いただく / 받다의 겸양어, 「~ていただく」문형

## 일반형·존경어·겸양어 대응표

| 일반형                 | 존경어                | 겸양어       |
| ------------------- | ------------------ | --------- |
| [[聞く]] (듣다/묻다, 기본형) | お聞きになる             | [[伺う]]    |
| [[尋ねる]] (묻다)        | お尋ねになる             | [[伺う]]    |
| [[行く]]・来る (가다·오다)   | いらっしゃる             | [[参る]]    |
| [[言う]] (말하다)        | おっしゃる              | [[申し上げる]] |
| [[見る]] (보다)         | ご覧になる              | [[拝見]]    |
| [[もらう]] (받다)        | — (해당하는 존경어 형태 없음) | [[いただく]]  |
| 食べる・飲む (먹다·마시다)     | 召し上がる              | [[いただく]]  |

※ 존경어 칸의 단어(お尋ねになる·いらっしゃる·おっしゃる·ご覧になる·召し上がる)는 아직 위키 페이지가 없어 링크하지 않았다 (생성 후보).

## 경어의 종류

- **존경어 (尊敬語)** — 상대방(또는 상대방 쪽 사람)의 행위·상태·소유물을 높여 표현하는 말. 주어가 상대방일 때 쓴다. 예: いらっしゃる(가시다/오시다/계시다), おっしゃる(말씀하시다), ご覧になる(보시다).
- **겸양어 (謙譲語)** — 자신(또는 자신 쪽 사람)의 행위를 낮추어 말함으로써 상대방을 높이는 말. 주어가 나일 때 쓴다. 예: 伺う(찾아뵙다/여쭙다), 申し上げる(말씀드리다), いただく(받다).
- **정중어 (丁寧語)** — 상대가 누구든 관계없이 말투 자체를 정중하게 하는 말. です・ます가 대표적이며, 위 두 유형과 달리 행위의 주체를 높이거나 낮추지 않는다.
- **미화어 (美化語)** — お/ご를 붙여 말을 부드럽고 품위 있게 만드는 것. 예: お茶(차), ご飯(밥). 상대를 높이거나 낮추는 기능은 없다.
