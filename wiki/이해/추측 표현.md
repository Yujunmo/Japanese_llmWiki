# 추측 표현 — ようです · そうです · らしい · みたいだ

일본어에서 「~인 것 같다 / ~한 모양이다 / ~라고 한다」류의 **추측·판단·전문(伝聞)** 을 나타내는 대표 4개 표현. 어감·근거의 성격·문체(문어/구어)가 조금씩 달라 상황에 맞게 골라 쓴다.

---

## 비교표 (한눈 요약)

| 표현 | 성격 | 근거 | 문체 | 대표 뉘앙스 |
|---|---|---|---|---|
| **ようです** | 추측·판단 | 화자의 관찰·감각·논리 (주관적 판단) | 문어·격식 | "내가 보기엔 ~인 것 같다" |
| **みたいだ** | 추측·판단 | 〃 (ようです와 거의 동의) | 구어·친근 | ようです의 캐주얼판 |
| **そうです**(양태) | 양태·인상 | 눈앞의 겉모습·낌새 | 중립 | "(보아하니) ~해 보인다" |
| **そうです**(전문) | 전문(伝聞) | 남에게서 들은 이야기 | 중립 | "~라고 한다 / ~라더라" |
| **らしい** | 추측·전문 | 객관적 근거(뉴스·소문·정황) | 중립 | "정황상 ~인 모양이다" |

- **ようです ↔ みたいだ**: 의미는 거의 같고 **문체 차이**(문어 vs 구어).
- **そうです**: 같은 형태로 **양태(見た目)**·**전문(伝聞)** 두 용법. **접속이 달라서** 구분된다 (아래 접속표 참조).
- **らしい**: 소문·정황에 근거한 추측. `[TODO: そうです(전문)와의 미묘한 차이 정리 — らしい는 근거 판단이 화자 몫, そうです(전문)는 순수 인용에 가까움]`

## 접속표

### ようです

| 품사 | 기본형 | ようです 연결 |
|---|---|---|
| 명사 | 学生だ | 学生**のようです** |
| な형용사 | 静かだ | 静か**なようです** |
| い형용사 | 高い | 高い**ようです** |
| 동사 | 行く | 行く**ようです** |

### みたいだ
**기본형에 그대로 붙는다** (명사·な형용사는 だ를 뺀다).

| 품사   | 기본형 | みたいだ 연결    |
| ---- | --- | ---------- |
| 명사   | 学生だ | 学生**みたいだ** |
| な형용사 | 静かだ | 静か**みたいだ** |
| い형용사 | 高い  | 高い**みたいだ** |
| 동사   | 行く  | 行く**みたいだ** |

명사·な형용사에서 `の`·`な`가 붙지 않는 점이 ようです와 다르다.

### そうです — 양태(様態)

**어간에 붙는다.**

| 품사 | 기본형 | そうです 연결 |
|---|---|---|
| い형용사 | 高**い** | 高**そうです** (い 탈락) |
| な형용사 | 静か**だ** | 静か**そうです** (だ 탈락) |
| 동사 | 降**る** | 降り**そうです** (ます 어간) |

예외: `いい → よさそうです`, `ない → なさそうです`. 명사에는 원칙적으로 붙지 않는다.

### そうです — 전문(伝聞)

**기본형(보통형)에 그대로 붙는다.**

| 품사 | 기본형 | そうです 연결 |
|---|---|---|
| 명사 | 学生だ | 学生**だそうです** |
| な형용사 | 静かだ | 静か**だそうです** |
| い형용사 | 高い | 高い**そうです** |
| 동사 | 行く | 行く**そうです** |

`降りそうです` (곧 내릴 것 같다 — 양태) vs `降るそうです` (내린다고 한다 — 전문) — **접속 형태가 다르다.**

### らしい

**기본형에 그대로 붙는다** (명사·な형용사는 だ를 뺀다).

| 품사 | 기본형 | らしい 연결 |
|---|---|---|
| 명사 | 学生だ | 学生**らしい** |
| な형용사 | 静かだ | 静か**らしい** |
| い형용사 | 高い | 高い**らしい** |
| 동사 | 行く | 行く**らしい** |

## 헷갈리기 쉬운 포인트

- **そうです 양태 vs 전문**: 접속 형태(어간 vs 기본형)로 구분. 「降りそうです」·「降るそうです」로 나란히 놓아 반복 학습.
- **ようです vs らしい**: 근거의 방향이 다르다. **ようです** = 안쪽(내 관찰·감각), **らしい** = 바깥쪽(정황·소문). `[TODO: 확실한 예문으로 대비 정리]`
- **みたいだ의 문체**: 격식 있는 문서·프레젠테이션에는 쓰지 않는다. ようです로 바꾸는 편이 안전.
